# Open SQL Lab

SAP Standard ABAP 7.62 Open SQL 독학용 브라우저 앱입니다. SCARR, SPFLI, SFLIGHT, SBOOK의 작은 가상 데이터만 사용하며 SAP 시스템이나 데이터베이스에 연결하지 않습니다.

## 실행

이 폴더에서 PowerShell을 열고 다음 명령을 실행합니다.

```powershell
py -m http.server 8000
```

브라우저에서 [http://localhost:8000](http://localhost:8000)을 엽니다. `index.html`을 직접 열어도 동작하지만, 로컬 웹 서버 실행을 권장합니다. 종료할 때는 PowerShell 창에서 `Ctrl+C`를 누릅니다.

## 주요 기능

- 난이도와 주제별 무작위 문제, seed 기반 재현과 최근 출제 회피
- 입력 중 ABAP 키워드·허용 필드 자동완성, 키보드 탐색과 SQL 구문 빠른 삽입
- 프로젝트 전체 코드 추가·편집, SELECT 패턴에서 테이블·필드·호스트 변수 추출
- 선택 프로젝트 한 개를 집중 연습하거나 선택한 프로젝트 풀에서 무작위 출제
- 프로젝트별 전체 조회, 필요한 열만 조회, 정렬 추가, 원본 WHERE 조건 유지 유형을 섞고 최근 유형 반복을 줄임
- 문제 편집기에서 답안 제출 전에도 SELECT 부분을 가상 테이블에 실행하고 결과 행을 미리 보기
- 독립 SQL 실습 화면에서 SELECT 조각을 작성하고 행 조회·필터·GROUP BY·정렬 예제를 바로 실행
- Open SQL 요구사항 체크리스트 평가, 단계별 힌트, 제출 후 모범 답안
- 제한된 조회 패턴을 가상 데이터에 적용한 실행 결과
- 오답 및 별표 복습, 제출 코드·힌트 단계·복기 메모 저장
- Local Storage 자동 저장, JSON 내보내기와 가져오기
- 스키마·용어 도움말, 반응형 한국어 화면

## 지원 범위

평가기는 브라우저에서 실행되는 가벼운 규칙 검사기입니다. 별도 가상 실행은 SELECT/FROM, 열 지정, 간단한 WHERE 조건, DISTINCT, COUNT/MIN/MAX/SUM/AVG, GROUP BY, ORDER BY, UP TO 등의 제한된 패턴을 처리합니다. JOIN과 일부 복합 조건 등 지원하지 않는 문법은 실행 오류로 표시합니다. 임의의 ABAP 코드를 파싱하거나 실제 SAP 컴파일러와 동등하게 검증하지 않습니다. 결과 데이터는 앱의 가상 행 또는 등록 프로젝트의 예시 행만 사용합니다. 모범 답안과 제출 코드는 SAP GUI에서 문법 검사 및 실행 결과를 별도로 확인하세요.

변경 SQL 템플릿은 가상 `ZLAB_BOOKING` 대상으로만 다룹니다. 앱은 표준 테이블 변경을 허용하지 않으며 실제 DB 변경, COMMIT, SAP 인증 기능이 없습니다. 데이터와 프로젝트 전체 코드는 현재 브라우저 Local Storage에 보관됩니다. 프로젝트 코드 분석은 SELECT/FROM/WHERE/INTO의 이름 추출을 돕는 수준이며, 직접 확인 후 저장해야 합니다.
